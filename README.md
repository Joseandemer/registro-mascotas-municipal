ANÁLISIS DEL REGISTRO MUNICIPAL DE MASCOTAS – 2023–2025

Herramientas utilizadas:

Excel

SQL / MySQL

Power BI

Descripción:
Proyecto de análisis de datos enfocado en el estudio del registro municipal de mascotas correspondiente al período 2023–2025. Se analizan indicadores como el volumen total de registros, distribución anual, comparación entre caninos y felinos, razas más registradas y tendencias de nacimiento. El análisis permite identificar patrones relevantes y apoyar la toma de decisiones en la gestión pública y el control de registros municipales.
